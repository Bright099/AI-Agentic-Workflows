# RAG PDF Chatbot

A simple Retrieval-Augmented Generation project that loads a PDF, splits it into chunks, stores embeddings in FAISS, and answers questions using an LLM.

## Tech Used

- Python
- LangChain
- FAISS
- Google Gemini API
- PyPDFLoader

## How to Run

1. Clone the repository
2. Install dependencies:

pip install -r requirements.txt
